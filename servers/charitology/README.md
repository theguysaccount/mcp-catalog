# Charitology public research

Endpoint: https://os.charitology.org/mcp
Guide: https://os.charitology.org/mcp.html

Three read-only tools search four already-published datasets (interventions, charity index entries, nonprofit benefits and bibliography sources), read an exact public record, and report bounded coverage. No authentication is required.

Draft review states, unknowns, source references and source-specific rights remain explicit. Depth classifications are hypotheses, not charity ratings or verified impact estimates. Export dates are not verification dates.

The isolated function imports no Charity OS database, account or mail modules and forwards no incoming credentials to the public dataset API. Private OS accounts, donors, participants, documents, enrollments, messages and financial actions are unavailable.
