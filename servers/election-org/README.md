# Election.org

Read-only public U.S. civic records with source links, reporting periods and coverage limits.

- Streamable HTTP MCP: https://election.org/api/mcp
- Official guide: https://election.org/data/api/access
- Authentication: none

No private voter records, political targeting or voting recommendations. Missing data is not zero, FEC filing is not proof of ballot certification, and campaign funds are not personal net worth.
