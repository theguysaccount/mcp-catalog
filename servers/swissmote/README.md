# Swissmote public jobs

MCP endpoint: https://api.swissmote.com/v2/api/public/mcp
Connection metadata: https://api.swissmote.com/v2/api/public/mcp/info

This anonymous read-only MCP reuses the existing public job-board API. It includes only published, active, unexpired self-platform job cards and public apply links. Existing employer confidentiality and salary visibility rules remain in place. It cannot read candidates, applications, resumes, interview information or private account records, and cannot score, hire, reject, message or submit anything. Account-scoped hiring workflows require separate supported authorization and validation.
