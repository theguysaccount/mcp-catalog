# MyLastWill

Prepare a U.S. will and look up state will requirements, charities and bequest language.

- Website: https://mylastwill.org
- Streamable HTTP MCP: `https://mylastwill.org/mcp`
- Official guide: https://mylastwill.org/agents/
- Authentication: none

The registry manifest describes the hosted product; this repository contains connection metadata, not its private implementation. Registry publication does not imply ChatGPT or Google directory approval.
