# Arcade.fun

Endpoint: https://arcade.fun/mcp

The existing seven-tool server supports public experience discovery and creator-owned experience/version/build/entry/cover management. The public list requires no credentials; creator status and updates require the existing experience owner key. Keep owner keys in secure storage and preserve existing versions unless the creator authorizes changes.

This catalog adds no wallet, purchase or wagering workflow. Initial verification used initialization, tool-schema discovery and the public experience list only; no game, key, version or upload was created.
