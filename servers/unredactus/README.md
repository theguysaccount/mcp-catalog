# Unredactus metadata research

MCP endpoint: https://unredactus.com/api/mcp

Connection metadata: https://unredactus.com/agents.json

Only existing public source research is exposed. No private accounts, reviews, participant records, conversations or workspaces. Preserve source citations, dates, coverage, methodology and uncertainty.
Unredactus is a pinned source-attributed snapshot, not a live monitor. Source labels are triage, not verified redactions or evidence of motive. CC BY-NC-SA 4.0 and source rights apply; no removed passages or personal search are exposed.
