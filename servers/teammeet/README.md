# TeamMeet

Start meetings and work with meeting transcripts, notes, recordings and follow-up tasks.

- Website: https://teammeet.ai
- Streamable HTTP MCP: `https://teammeet.ai/mcp`
- Official guide: https://teammeet.ai/developers
- Authentication: api_key

The registry manifest describes the hosted product; this repository contains connection metadata, not its private implementation. Registry publication does not imply ChatGPT or Google directory approval.

Set `TEAMMEET_API_KEY` in your MCP client’s secret storage. Fixed API-key authentication is not currently accepted by the public ChatGPT submission portal; an OAuth adaptation is a separate release requirement.
