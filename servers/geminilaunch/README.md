# GeminiLaunch

Connect a GeminiLaunch account to agents using its authenticated product MCP tools.

- Website: https://www.geminilaunch.com
- Streamable HTTP MCP: `https://www.geminilaunch.com/api/mcp`
- Official guide: https://www.geminilaunch.com/mcp
- Authentication: oauth

The registry manifest describes the hosted product; this repository contains connection metadata, not its private implementation. Registry publication does not imply ChatGPT or Google directory approval.

Use your own account and consent to the OAuth scopes in the product’s connection flow. No access tokens belong in this repository.
