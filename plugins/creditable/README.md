# Creditable Discovery

Find published investor pitch routes, with the source and check date. Look up startup credit guides or choose an opt-in SyncedIn introduction for investors and cofounders.

In Claude Code, run `/plugin marketplace add theguysaccount/mcp-catalog` followed by `/plugin install creditable@creditable-founder-tools`. In a client that accepts remote MCP, add `https://creditable.vc/mcp/discovery` with Streamable HTTP and no authentication.

Try “Where does Seedcamp publish its pitch instructions?”, “Find pre-seed pitch forms” or “Where can I meet a cofounder?” Results use a dated public snapshot. The discovery connection has three read-only tools. It cannot send messages, submit applications or access private applicant records.
